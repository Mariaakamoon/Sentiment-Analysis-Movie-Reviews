# CineScope — Sentiment Analysis of Movie Reviews

CineScope is a Flask movie discovery interface that combines a local TMDB 5000 dataset with the existing VADER review classifier in `sentiment.py`. The local catalog does not need a TMDB API token. Dataset metadata is historical and does not include current ratings, trailers, or poster paths.

## Run on Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Download the TMDB 5000 movie and credits CSV files and place them at `data/tmdb_5000_movies.csv` and `data/tmdb_5000_credits.csv`. These dataset files are intentionally excluded from Git. The local dataset powers the movie library without requiring a TMDB token; an API token can optionally be configured for live TMDB details.

Create a free Gemini API key from Google AI Studio (https://aistudio.google.com/) and add it, along with any optional provider credentials, to `.env`:

```env
TMDB_API_TOKEN=your_tmdb_read_access_token
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.1-flash-lite
PORT=5002
```

Do not commit `.env` or share your tokens. Then start the app:

```powershell
python main.py
```

Open `http://127.0.0.1:5002`. The site has separate pages for `/movies` (popular English and Hindi titles), `/movie/<id>` (dataset details, with live TMDB fallback when configured), `/analyzer` (VADER review analysis with optional Gemini insights), and `/ask` (movie Q&A grounded in metadata, with spoiler safety and a deterministic fallback). Set `PORT` in `.env` if you want another port.

## Checks

```powershell
pytest
```

The interface supports dark/light themes, keyboard-focusable controls, reduced motion, missing-poster states, spoiler boundaries, and TMDB attribution. Movie data is sourced from the local TMDB 5000 dataset or live TMDB; sentiment results are generated by VADER and are not movie ratings.
